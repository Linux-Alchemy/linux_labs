# 📚 Linux+ Study Labs

This folder contains a curated collection of labs designed to support my preparation for the CompTIA Linux+ certification exam. Each lab is built with a focus on real-world, command-line tasks and hands-on learning.
These are not just practice exercises — they're working examples of how Linux skills are applied in actual system administration, scripting, and troubleshooting.

---

## 🎯 Purpose

- Reinforce key concepts from the Linux+ (XK0-005) objectives
- Build repeatable and testable hands-on experience
- Provide clearly documented labs with screenshots, explanations, and real terminal output

---

## 🧪 Included Labs

- `permissions/` – File ownership, permission sets, chmod, chown, sticky bits, and ACLs  
- `storage/` – Partitioning, formatting, and mounting additional drives  
- `users_groups/` – Creating, modifying, and auditing users and groups  

*More labs will be added as I progress through the exam objectives.*

---

## 🛠️ Tools Used

- Rocky Linux (virtualized environment)
- Bash shell
- Visual Studio Code
- VMware Workstation Pro

---

## 🔍 Notes

Each lab folder contains:
- `README.md` or `.md` instruction files
- A `/screenshots` directory for visual reference
- Inline explanations to highlight **why each step matters**

---

This structure keeps the Linux+ labs separate from my general-purpose Linux projects while showcasing focused, cert-aligned practice.
